
# TRACE99

AI-Powered Incident Investigation Platform

## Overview

TRACE99 is a full-stack application designed to help
software engineers, SREs, and support teams investigate
application incidents using uploaded technical evidence.

## Tech Stack

- Backend: FastAPI
- Frontend: React + Vite + Tailwind CSS
- Database: PostgreSQL
- Vector Database: Pinecone
- LLM: Google Gemini with Groq fallback
- Orchestration: LangGraph
- Retrieval: Hybrid RAG + Corrective RAG

## Planned Features

- Secure user authentication
- Incident management
- Multi-file evidence upload
- Semantic and keyword retrieval
- Six-agent Corrective RAG
- Evidence-grounded investigation reports
- Human review and approval
- Evaluation and tracing
